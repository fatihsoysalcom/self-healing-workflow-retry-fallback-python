# Self Healing Workflow Retry Fallback Python

This Python script simulates a workflow step with self-healing capabilities. It attempts a primary task, retries it a few times if it fails, and then executes a fallback action to ensure business continuity if all primary attempts are unsuccessful. This demonstrates a core pattern for designing robust automation systems that reduce manual intervention.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
